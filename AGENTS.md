# Contributor instructions

Read [the current release and acceptance register](docs/apex-acceptance-checklist.md) before making changes, and [the continuity guide](docs/AI_HANDOFF.md) for approved design and source mapping.

Preserve approved company positioning, artwork, typography and links. Use shared venture and company data for visible copy and structured data. Check sitemap, robots, metadata and canonical routes when relevant; leave correct files unchanged. Keep factual limitations in appropriate legal and engineering context. Record completed work and new evidence in the current register, with historical records dated separately. Build-test the exact branch, obtain review, merge reviewed changes, and verify production deployment separately using the authorized release process. Never infer live status from merge alone.
